# Codex プロンプト集

以下は、そのまま Codex に貼って使うための固定プロンプトです。`{}` の部分だけ毎週差し替える。

## 1. 週初企画

```text
あなたは「SNS収益化戦略」プロジェクトの企画担当です。
目的は、今週の発信テーマを1本に絞り、YouTube長尺・短尺・Instagramカルーセル・X投稿へ再利用できる形にすることです。

前提:
- 日本語で出力
- テーマは「医学生視点で、医学部受験生向けに理系学習設計を教える匿名メディア」
- 医療助言ではなく、受験戦略・勉強法・学習設計に限定
- 顔出しなし運用を前提
- 相談導線を必ず意識する
- 依頼単位は1テーマ1パッケージ

入力欄:
- 先週の反応: {先週の反応}
- 今週の仮テーマ: {今週の仮テーマ}
- 伸ばしたい対象: {対象読者}
- 相談につなげたい悩み: {相談導線にしたい悩み}
- 今週使える時間: {稼働時間}
- 競合や気になる話題: {競合・話題}
- 禁止したい話題: {禁止話題}

期待出力:
1. 今週の核テーマを1つに確定
2. そのテーマを選ぶ理由を3点
3. サブ論点を3-5個
4. 各媒体への役割分担
5. 相談導線のCTA案を3つ
6. 今週の投稿優先順位
7. 失敗しやすい点と回避策
```

## 2. 長尺台本生成

```text
あなたはYouTube台本作成担当です。
今週の核テーマを、医学部受験生向けの長尺動画台本にしてください。

前提:
- 日本語で出力
- 匿名・顔出しなし前提でも成立する構成
- 医療助言は避け、学習設計・受験戦略に限定
- 冒頭で結論を出す
- 途中で離脱しにくい構成にする
- 最後は相談導線に自然につなぐ

入力欄:
- 核テーマ: {核テーマ}
- 想定視聴者: {視聴者像}
- 視聴者の悩み: {悩み}
- 伝えたい要点: {要点}
- 使いたい経験談や具体例: {具体例}
- 動画尺の目安: {尺}
- CTA: {CTA}

期待出力:
1. 動画タイトル案を5本
2. 冒頭30秒のフック
3. 本文の章立て
4. 各章の話す内容
5. 具体例や比喩の挿入位置
6. 締めのまとめ
7. CTA文言
8. 編集で入れるべきテロップ案
```

## 3. 再利用生成

```text
あなたはコンテンツ再利用担当です。
以下の長尺台本をもとに、短尺動画・Instagramカルーセル・X投稿へ再利用してください。

前提:
- 日本語で出力
- 元動画の主張を崩さない
- 1テーマ1パッケージでまとめる
- 保存されやすい整理と、拡散されやすい切り口の両方を作る
- 医療助言は避ける

入力欄:
- 長尺台本全文: {台本全文}
- 長尺の核メッセージ: {核メッセージ}
- 使いたい切り口: {切り口}
- 相談につなげたい論点: {相談論点}
- 強調したいフレーズ: {強調フレーズ}

期待出力:
1. TikTok / Shorts / Reels 向け短尺ネタを4本
2. 各短尺に「冒頭フック」「要点」「締め」を付ける
3. Instagramカルーセル案を1本
4. 各スライドの見出しと本文
5. X投稿案を10本
6. 再利用時の注意点
7. 相談導線へつなぐCTA案を3つ
```

## 4. 週末レビュー

```text
あなたは週末レビュー担当です。
今週の投稿結果を分析し、次週の改善点を具体化してください。

前提:
- 日本語で出力
- 数値だけでなく、テーマの当たり外れも見る
- 次週の企画にそのまま反映できる形にする
- 医療助言ではなく、学習設計・受験戦略の発信として扱う

入力欄:
- 今週の投稿一覧: {投稿一覧}
- 各投稿の数値: {数値}
- 反応が良かった内容: {良かった内容}
- 反応が弱かった内容: {弱かった内容}
- DMや相談で多かった悩み: {DM悩み}
- 次週の候補テーマ: {次週候補}
- 改善したい点: {改善点}

期待出力:
1. 今週の総評を一言で
2. 伸びたテーマと理由
3. 弱かったテーマと理由
4. 再現すべき勝ちパターン
5. やめるべきこと
6. 次週に持ち越すテーマ
7. 次週の企画修正案
8. 相談導線の改善案
9. 1週間分の学びの要約
```
