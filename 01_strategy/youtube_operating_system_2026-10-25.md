## 0. 結論（先に読む1ページ）

**チャンネルは1本、視聴者は1種類、約束は1文。**

- チャンネル: **理系再建ラボ**（名前は維持。顔出しなし、声は本人）
- 第一視聴者: **医学部志望の高校生・浪人生のうち、独学寄りで理系が崩れかけている人**（地方・非進学校・部活引退後に本気になった層）。その保護者が隣で見る前提で作る
- 約束: **「医学生の家庭教師が、理系の崩れを『配分と順番』で立て直す」**
- 差別化: ①実在の指導事例（匿名化）に基づく「崩れ方の型」と「直し方」、②偏差値20台から医学部に入った本人の一次経験、③AI を禁止も神格化もせず「補助線」として手順で見せる、④家庭教師視点なので保護者にも通じる
- 収益: 広告は目的にしない。日本の教育系 RPM は約 2.6 ドル／1,000再生（二次）で、年5万再生でも約2万円。**収益の本体は AIYouMe の商品（学習設計の相談、講師向け教材整備）**。YouTube は信頼と検索資産と導線
- 収益化要件（1,000人＋4,000時間/12か月）: 月あたり視聴 333 時間、平均視聴 4.5 分なら月 4,400 再生。長尺 40 本で平均 1,300 再生/本。**到達は現実的だが、12 か月の継続が条件**
- 時期: **CBT（2026-11-13）までは1本も作らない。** 11/14 から週1本、1〜3月の受験期は週2本
- 停止条件: 12 本公開して平均視聴割合 30% 未満かつ CTR 3% 未満なら形式を変える。登録 50 人未満なら視聴者か題材を変える。8 週で承認 16 本未満（投稿基盤の運用判定）ならチャンネル凍結

**やらないこと**: AI ペルソナに語らせる、量産テンプレ、医療・健康の助言、KUSEIRO・@8jxp8 との導線接続、複数チャンネルの同時立ち上げ、Shorts だけで収益化を狙う、1〜3月以外に週2本。

**実査から得た示唆**

1. **「医学生の設計論」の個人枠は空いている。** 医大生とあ（24本で1.9万人、中央値2.5万再生）が需要を証明し、3か月更新が止まっている。同じ看板の「いいいし」は5年前に休止。Cognition も4か月止まっている。継続するだけで差になる。
2. **週1本で十分に戦える。** 上位の塾系は毎日1〜2本だが、個人で1〜4万人に達したチャンネルは月数本〜週1本。本数より「結論型のフック」と「当事者性」が効いている。
3. **効くフックの型（実測）**: 「【医大生の結論】結局、これが最強です」（6.2万）、「その暗記法、100％忘れます」（13万）、「数弱克服」（22万）、「浪人生の大半が失敗に終わる理由」（7,722、小規模チャンネルでは上位）、「E判定でも受かる人の違い」（5,957）。断定・否定・結論先出し。うちは「崩れの型」「配分と順番」をこの型に載せる。
4. **当事者の実録は爆発力がある**が、合格後に止まる。桃白白の合格発表 154 万再生、よるの参考書回 12 万。P3（CBT 実録）は「止まらない実録」として設計し、合格・終了で終わらないテーマ（学習 OS）に接続する。
5. **収益導線の実例**: 桃白白のコーチング募集（8,659 再生）、ガチノビの有料講座、PASSLABO のメンバーシップ。登録 5,000〜1 万人規模でも個別指導・講座の導線は成立している。§8 の S1（単発相談）は現実的。
6. **大手は医学部特有の配分を扱わない**（武田塾は一般受験、PASSLABO は数学・イベント中心）。理科2科目・共テ比率・面接・浪人の配分は、うちの P2 で独占できる。
7. **顔出しなしの可否**: 個人勢の顔出し有無は今回未確認。音声と図解で成立する動画（医大生とあの構成）が伸びている事実はある。顔出しなしは制約ではなく型にする。

## 2. チャンネルのポジショニング

- **一言**: 理系再建ラボ｜医学生の家庭教師が、崩れた理系を配分と順番で立て直す

## 6. 視聴維持フレームワーク

**構造（10分の場合）**

| 時間 | 役割 | 書き方 |
| --- | --- | --- |
| 0:00〜0:05 | 結論か具体的な場面 | 「数学の偏差値70で医学部に落ちた生徒がいます」「結論、理科は夏までに終わらせない方がいい人がいます」 |
| 0:05〜0:20 | 誰向け・得るもの・構成（3つ） | 「高2〜浪人の独学組に、崩れの3つの型と、来週からの直し方を話します」 |
| 0:20〜2:00 | ブロック1（型／事例） | 具体→一般化。実物（匿名の計画表）を画面に |
| 2:00〜4:00 | ブロック2（原因） | ここで一度「よくある誤解」を否定して注意を引き戻す |
| 4:00〜7:00 | ブロック3（手順） | 1週間の具体的な手順。画面にチェックリスト |
| 7:00〜9:00 | 注意点と例外 | 「この人には当てはまらない」を言う（信頼） |
| 9:00〜10:00 | 次の一手 | 要約しない。「次に見る動画」と「今日やる1つ」。終了画面へ |

**維持の仕掛け**: 30〜45 秒ごとに画面の種類を変える（図解→実物→テロップ→本人の手書き）。各ブロックの最後に次のブロックへの問いを置く（オープンループ）。冒頭で約束した「3つ」は必ず回収する。
**目標値**: 30 秒時点の維持 70% 以上、平均視聴割合 45%（8〜12分）、CTR 5%（検索流入が主なら達成しやすい。二次の目安では 4〜6% が良好）。
**毎週の分析**: Studio の維持率グラフで最大の谷を1つ特定し、その時間帯のブロックを次回で直す。1 週間に直すのは1点だけ。

## 7. 成長システム

1. **検索ファースト**: 各動画は検索語1つを主語にする。語の候補群（公開前に Studio と検索候補で確認）: 医学部 受験 勉強法 / 医学部 浪人 計画 / 医学部 高2 / 物理 生物 選択 医学部 / 医学部 数学 伸びない / 共通テスト 後 二次 配分 / 宅浪 医学部 / 医学部 受験 親。
2. **シリーズ化**: P1 は「崩れの型 #1〜#12」、P2 は「残り◯日の配分」で再生リストを作り、終了画面と固定コメントで次へ回す。
3. **Shorts → 長尺**: Shorts は長尺の1ブロックの切り出しのみ。説明欄に長尺リンク。Shorts 単体のネタは作らない。
4. **X / Threads への再利用**: sns-video-pipeline で、長尺1本から X 投稿 3 本・Threads 2 本・Shorts 3 本を生成し、本人が承認。本文にリンクは置かない（X の到達と料金）。
5. **コメント運用**: 公開から 48 時間は本人が返信。質問はメモし、月1ライブと次の動画の題材にする。自動返信はしない。
6. **協業**: 登録 300 人を超えたら、医学生または個別指導塾のチャンネルと1本ずつ出演交換。KUSEIRO 系とは絶対に組まない。
7. **実験枠**: 10 本に1本は型を外す（例: 1本丸ごと事例、質問回答のみ）。採否は維持率と登録純増で判断。
8. **外部の起点**: ai-yu-me.com に「動画一覧」ページを置き、LINE 登録者に新作を週1通で知らせる（LINE は既に導線がある）。
