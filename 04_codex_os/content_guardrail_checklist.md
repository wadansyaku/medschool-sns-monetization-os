# Content Guardrail Checklist

週次パッケージ、動画 props、投稿文を出す前に確認する。迷った場合は、短尺の強さではなく `YouTube 長尺として登録理由になるか` を優先する。

## 1. ブランド

- 公開ブランド名が `理系再建ラボ｜医学につながる理系` からズレていない
- 旧テーマ `受験相談メディア` に戻っていない
- チャンネルの約束 `理系でつまずく人を、医学で使える理解まで連れていく` とつながっている

## 2. レイヤー

- 企画が次のどれか 1 つに固定されている
  - `高校理系ブリッジ`
  - `医学学習OS`
  - `AI実務`
- 短尺、カルーセル、X 投稿でレイヤーが変わっていない
- AI は補助線であり、AI 活用そのものが主役になっていない

## 3. YouTube 長尺主軸

- まず長尺のタイトル、サムネ、冒頭30秒、章立てがある
- 短尺 4 本は長尺の別角度であり、別テーマ化していない
- Instagram と X は長尺の理解補助または接触頻度維持になっている
- 次に見る長尺が 1 つ以上示されている
- タイトルが相談、合格保証、医療断定に寄っていない
- サムネが煽りだけで終わらず、長尺を見る理由を残している
- 冒頭30秒が `対象 / 悩み / 結論 / 見続ける理由` に分解されている

## 4. 医療境界

- 医療助言、診断、治療判断に見える表現がない
- 症状の安心判断や医学的効能の断定に踏み込んでいない
- 医学は `理解の接続先` として扱っている
- 合格保証や成果保証に見える表現がない

## 5. CTA

- CTA は長尺視聴、保存、次動画回遊を優先している
- 相談導線は必要な場合のみ二次目的として添えている
- 相談導線がタイトル、サムネ、冒頭30秒を支配していない

## 6. 実装前 gate

- `02_content_os/packages/` の正本が更新されている
- `05_video_os/src/data/videoPackages.ts` の props が正本から逸れていない
- `05_video_os/video-packages.manifest.json` に composition ID と sourcePath がある
- `03_analytics_os/experiment_backlog.md` に仮説がある
- `03_analytics_os/post_log.csv` に投稿予定行がある
- `npm run validate:packages` が通る

## 7. KPI gate

- primary metric が 1 つだけ選ばれている
- 成功、保留、修正の条件が文章で書かれている
- 相談数や DM 数だけで採用判断しない
- 次週に変える要素が `タイトル / サムネ / 冒頭 / 章立て / 回遊導線` のどれかに絞られている
